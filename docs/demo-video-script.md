# LyHermes Demo 视频脚本

> 时长：3-4 分钟 | 风格：屏幕录制 + 旁白 | 适合平台：B站、抖音、小红书、Twitter

---

## 开场（15秒）

**画面**：淡入到 macOS 桌面，鼠标点击 LyHermes 图标启动应用

**旁白**：
> "你的 AI 工具是不是这样的？每次打开都是一个新的聊天窗口，上下文说丢就丢，想让它每天帮你做点什么还得手动操作。
> 
> 今天介绍一个不一样的思路：把 AI 当成员工来管理。"

**画面**：应用启动，展示水墨风登录页（稍微停顿，让观众看到视觉设计）

---

## 第一部分：安装与初始化（30秒）

**画面**：
1. 展示登录后的主界面
2. 点击"设置" → "安装 Hermes Agent"
3. 展示安装向导：检测环境 → 下载 → 配置 → 完成
4. 进度条走完后显示"安装成功"

**旁白**：
> "落云.Hermes 是一个 AI 员工管理平台。第一次打开，它会自动帮你安装和配置底层的 Hermes Agent 引擎。
>
> 不需要手动配 Python、配虚拟环境、配依赖——点一下，等进度条走完就行。"

---

## 第二部分：员工管理（60秒）

**画面**：
1. 切换到"员工列表"页面，展示已有的几个员工（银月、币可、张三丰）
2. 点击"新建员工"按钮
3. 填写表单：
   - 名字："周报助手"
   - 角色："每周一生成团队周报"
   - 选择模型：DeepSeek-V3
   - 启用工具：文件读取、代码执行
4. 保存后新员工出现在列表中
5. 点击员工头像，展示详情面板：人格设定、技能、Token 用量

**旁白**：
> "在 LyHermes 里，每个 AI profile 都是一个'员工'。
>
> 你可以给每个员工设定名字、角色、使用什么模型、启用哪些工具。
> 比如这个'周报助手'，我让它每周一早上自动生成团队周报。
>
> 每个员工有独立的记忆、独立的技能配置、独立的 Token 用量统计。"

**画面**：快速切换几个不同员工的对话界面，展示不同的上下文

---

## 第三部分：对话与协作（45秒）

**画面**：
1. 点击"银月"（代码审查员），进入对话界面
2. 发送一条消息："帮我 review 刚才的提交"
3. AI 回复，展示代码高亮和分析结果
4. 展示拖拽文件上传功能
5. 展示 Markdown 渲染效果

**旁白**：
> "对话体验也是重点。支持 Markdown、代码高亮、文件拖拽上传。
>
> 但关键是——这些对话是有上下文的，有记忆的，不会因为刷新页面就消失。"

---

## 第四部分：定时任务（45秒）

**画面**：
1. 切换到"自动化"或"日程"页面
2. 展示任务列表：
   - 09:00 日报汇总 → 上次成功
   - 18:00 项目复盘 → 上次成功
   - 每 30 分钟巡检 → 运行中
3. 点击"新建任务"
4. 配置：选择员工"周报助手" → 设置 cron 表达式 `0 9 * * 1` → 选择投递渠道"飞书"
5. 保存后任务出现在列表中

**旁白**：
> "最实用的功能是定时任务。
>
> 你可以让 AI 员工按节奏工作：每天早上 9 点发日报，每周一早上生成周报，每半小时巡检一次服务器。
>
> 结果会自动推送到飞书、微信或钉钉。"

---

## 第五部分：Token 用量与数据（30秒）

**画面**：
1. 切换到"统计"或"用量"页面
2. 展示图表：
   - 本月 Token 用量趋势
   - 按员工分布（饼图）
   - 按模型分布（柱状图）
3. 点击"导出"按钮，生成 CSV 文件

**旁白**：
> "用 AI 最怕什么？账单惊吓。
>
> LyHermes 会按员工、按模型、按日期统计 Token 用量，让你知道钱花在哪了。"

---

## 第六部分：远程模式（30秒）

**画面**：
1. 切换到设置页面
2. 点击"切换为远程模式"
3. 输入远程服务器地址和 API Token
4. 连接成功后，界面和本地模式一样使用

**旁白**：
> "Agent 不一定非要跑在本机上。
>
> 你可以把 Agent 放在服务器长期运行，桌面端只负责连接、配置和观察。适合团队部署。"

---

## 录制建议

### 技术准备
- **录屏工具**：macOS 自带录屏（Cmd+Shift+5）或 OBS
- **鼠标高亮**：开启鼠标点击特效（macOS 可用 Pinpoint，Windows 可用 ClickShow）
- **分辨率**：1920x1080 或 2560x1440，确保文字清晰
- **语速**：中等偏慢，给画面切换留时间

### 剪辑建议
- 每个部分之间加 0.5 秒淡入淡出
- 关键操作（点击、输入）加缩放特效
- 背景音乐：轻柔电子乐，音量低于旁白
- 字幕：关键术语加高亮（如"员工"、"定时任务"、"Token 用量"）

### 平台适配
| 平台 | 时长 | 建议 |
|------|------|------|
| B站 | 3-4 分钟 | 完整版，加章节时间戳 |
| 抖音 | 60 秒 | 只保留第 2+3+4 部分，快节奏剪辑 |
| 小红书 | 90 秒 | 重点展示 UI 颜值 + 定时任务功能 |
| Twitter | 45 秒 | 快闪版，每部分 10 秒 |
