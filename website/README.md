# 落云.Hermes 官网

这是为当前项目定制的静态官网首页，可直接通过浏览器打开：

```text
website/index.html
```

本页复用了项目内的 `logo.png` 与 `login-bg.jpg`，并围绕当前源码中的能力组织文案：

- 桌面端自动安装、诊断、更新 Hermes Agent 引擎
- AI 员工/profile 管理
- 本机模式与远程客户端模式
- 定时任务聚合看板
- 飞书、微信、钉钉集成
- Web 嵌入访问与 Token 用量观测

对官方 Hermes Agent 的描述参考：

- https://github.com/NousResearch/hermes-agent
- https://hermes-agent.nousresearch.com/docs

正式发布前建议替换 `index.html` 中的下载链接为你的 GitHub Release、官网分发页或内测表单地址。
