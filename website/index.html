FAQ

官网上用户最关心的几个问题。

落云.Hermes 和官方 Hermes Agent 是什么关系？

落云.Hermes 是基于 Hermes Agent 生态构建的桌面工作台，重点是图形化安装、员工管理、远程控制、渠道集成和数据治理。

它是不是只能在本机使用？

不是。项目支持本机模式和 client_only 远程客户端模式，可通过 API Token 连接远程 Hermes 节点；同时内置 Web 服务供浏览器管理。

为什么强调 AI 员工？

Hermes profile 本身适合承载不同角色。落云.Hermes 将 profile 产品化为员工，让角色、人格、技能、模型、渠道和任务都能分开管理。

适合个人还是团队？

个人可以把它作为长期助理工作台；团队则可以用多员工、日程和办公渠道集成来承载日报、巡检、客服、研究等持续工作。

数据存在哪里？安全吗？

所有数据存储在本地 SQLite 数据库（~/.lyhermes/ 和 ~/.hermes/），不上传云端。支持备份导出和恢复导入。

支持哪些操作系统？

提供 Windows、macOS 与 Linux 桌面安装包。Windows 本机模式建议安装 Python 3.11+ 与 Git for Windows；远程客户端模式无需本机 Python。
